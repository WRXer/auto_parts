Сайт бу автозапчастей



Полностью работоспособный сайт бу автозапчастей.

Предполагает реализацию следующего функционала:

Бэкенд-часть проекта предполагает реализацию следующего функционала:

- Авторизация и аутентификация пользователей.
- Распределение ролей между пользователями (пользователь и админ).
- Восстановление пароля через электронную почту (не обязательно).
- CRUD для запчастей, заказов на сайте (админ может удалять или редактировать все запчасти, заказы).
- В заголовке сайта можно осуществлять поиск объявлений по названию, артикулу, марке - модели - поколению.
- Корзина, в которую можно добавлять запчасть и оформлять заказ.
- Всплывающее окно для быстрого заказа звонка.
- Т.к. заказчику не дали полный доступ к бд, сделано автоматическое обновление бд(скачиваем и преобразуем в эксель, редактируем нужные колонки, записываем).
- Автомобили-доноры, с которых сняты запчасти.
- Личный кабинет.
- ТГ-бот отправляющий уведомления админу/ менеджеру о новом заказе, запросе звонка(В админке можно добавлять айди, которому отсылать уведомления! Работать начинает после взаимодействия юзера с этим айди в боте /start).


Краткое техническое задание по порядку выполнения:
Этап I. Настройка Django-проекта.
Этап II. Создание модели юзера. Настройка авторизации и аутентификации.
Этап III. Описание моделей объявлений и отзывов.
Этап IV. Создание views и эндпоинтов.
Этап V. Определение permissions к views.


------------------------------------------------------------------------
ВАРИАНТ 1:

Запуск проекта производится через docker-compose

Перейти в папку auto_parts:
cd auto_parts

Создать .env файл, в нем прописать все свои данные, что есть в .env.sample

Выполнить команду:
docker-compouse up --build -d

------------------------------------------------------------------------
ВАРИАНТ 2:

Установить зависимости
pip install -r requirements.txt

Создать .env файл, в нем прописать все свои данные, что есть в .env.sample

Создайте базу данных psql -U (ваш логин в постгрес). 

Зайти в config/settings.py и загнать в DATABASES: HOST, PORT под #

Произвести миграцию таблиц в базу данных
python manage.py migrate

Загрузить фикстуры в базу данных, если вам они требуются

Запустить сервер
python manage.py runserver
